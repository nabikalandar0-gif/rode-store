# ویدیوی بخش هیرو

کد از قبل آماده‌ست — فقط کافیه فایل ویدیو رو دقیقاً با همین اسم اینجا بذاری:

```
hero.mp4
```

## مشخصات پیشنهادی فایل

- **فرمت**: mp4 (کدک H.264) — روی همه مرورگرها و موبایل‌ها بدون مشکل پخش می‌شه.
- **مدت زمان**: ۵ تا ۱۵ ثانیه، به‌صورت حلقه (loop) — چون ویدیو بی‌صدا و مداوم پخش می‌شه،
  هرچی کوتاه‌تر و روان‌تر باشه بهتره (مثلاً یه پلان آرومِ استودیو، یا نمای نزدیک از
  میکروفون).
- **رزولوشن**: ۱۹۲۰×۱۰۸۰ کافیه؛ رزولوشن بالاتر فقط حجم رو زیاد می‌کنه بدون فرق بصری
  محسوس روی صفحه.
- **حجم فایل**: تا حد امکان زیر ۱۰-۱۲ مگابایت نگه دار (با یه ابزار فشرده‌سازی مثل
  HandBrake یا حتی همون اپلیکیشن‌های آنلاین فشرده‌سازی ویدیو) — وگرنه لود اول سایت
  کند می‌شه، مخصوصاً برای کاربرهای موبایل.
- **بدون صدا لازم نیست نگرانش باشی** — چون مرورگرها فقط اجازه‌ی پخش خودکار (autoplay)
  به ویدیوهای بی‌صدا رو می‌دن، کد از قبل ویدیو رو موت (`muted`) پخش می‌کنه، فرقی نداره
  فایل اصلی صدا داشته باشه یا نه.

## اگر فایل رو نذاری چی می‌شه؟

هیچ اتفاق بدی نمی‌افته — همون عکس فعلی هیرو (با همون افکت زوم آروم) به‌جاش نمایش داده
می‌شه، بدون هیچ خطا یا فضای خالی در صفحه. هر وقت ویدیو رو اضافه کردی، خودکار جایگزین
عکس می‌شه.
