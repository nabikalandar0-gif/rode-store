# رود تهران — فروشگاه میکروفون و هدفون RØDE

یک وب‌سایت تک‌صفحه‌ای (single-page) با React + TypeScript + Tailwind CSS، ساخته‌شده با
ساختار استاندارد shadcn/ui.

## اجرای پروژه

نیاز به Node.js نسخه ۱۸ یا بالاتر دارید.

```bash
npm install
npm run dev
```

سپس آدرسی که در ترمینال نمایش داده می‌شود (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.

برای ساخت نسخه نهایی جهت آپلود روی هاست:

```bash
npm run build
```

خروجی در پوشه `dist/` قرار می‌گیرد.

## ساختار پروژه

```
src/
  components/
    ui/            ← کامپوننت‌های پایه (دقیقاً همان مسیر پیش‌فرض shadcn/ui)
      dock.tsx      ← منوی شناور پایین صفحه
      button.tsx
      input.tsx
      textarea.tsx
      label.tsx
    Nav.tsx          ← لوگو + منوی Dock
    Hero.tsx         ← بخش هیرو
    Products.tsx     ← بخش محصولات (میکروفون/هدفون)
    ProductCard.tsx
    Story.tsx        ← بخش داستان فروشگاه
    Consult.tsx      ← بخش فرم مشاوره
    ContactForm.tsx
    ContactInfo.tsx  ← بخش آدرس، تماس و فوتر
  data/products.ts   ← لیست محصولات — از اینجا محصول اضافه/حذف کنید
  context/inquiry-context.tsx  ← کلیک روی «مشاوره برای خرید» فرم را پر می‌کند
public/
  fonts/    ← راهنمای افزودن فونت کلمه
  products/ ← راهنمای افزودن عکس محصولات
```

> **چرا `components/ui`؟** این پوشه محل استاندارد کامپوننت‌های پایه در ساختار shadcn/ui
> است. نگه‌داشتن این مسیر باعث می‌شود اگر بعداً خواستید کامپوننت جدیدی از رجیستری
> shadcn اضافه کنید (`npx shadcn@latest add ...`)، بدون تداخل مسیر کنار بقیه بنشیند و
> از منطق صفحات (`components/*.tsx`) جدا بماند.

## قبل از انتشار، این موارد را جایگزین کنید

سایت همین الان کامل و بدون خطا اجرا می‌شود، اما چند بخش با محتوای نمونه/جایگزین پر
شده‌اند که باید با اطلاعات واقعی فروشگاه‌تان عوض شوند:

1. **فونت کلمه** — راهنما: `public/fonts/README.md` (تا قبل از افزودن، از فونت
   Vazirmatn به‌عنوان جایگزین نزدیک استفاده می‌شود).
2. **عکس محصولات** — راهنما: `public/products/README.md`.
3. **قیمت‌ها** — همه محصولات فعلاً «تماس بگیرید» نشان می‌دهند (`src/data/products.ts`)،
   چون قیمت واقعی بازار ایران را نمی‌دانستم. اگر می‌خواهید قیمت دقیق نمایش داده شود،
   مقدار `price` هر محصول را عوض کنید.
4. **آدرس، تلفن و ساعت کاری** — در `src/components/ContactInfo.tsx`، آبجکت `info`.
5. **لینک شبکه‌های اجتماعی** — همان فایل، آرایه `social`.
6. **ایمیل دریافت فرم مشاوره** — در `src/components/ContactForm.tsx`، مقدار
   `STORE_EMAIL`. فعلاً فرم با کلیک روی دکمه، ایمیل کاربر را باز می‌کند (`mailto:`)؛
   برای دریافت خودکار پیام‌ها در یک صندوق ورودی یا CRM، بهتر است این تابع را به یک
   سرویس واقعی مثل Formspree، EmailJS یا API خودتان وصل کنید.

## کتابخانه‌های اصلی

`react`، `tailwindcss`، `framer-motion` (برای انیمیشن منوی Dock)، `lucide-react`
(آیکون‌ها)، و `class-variance-authority` + `@radix-ui/react-slot` (برای کامپوننت
دکمه به سبک shadcn/ui).
